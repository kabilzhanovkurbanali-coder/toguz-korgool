# Тогуз Коргоол

Кыргызская настольная игра девяти лунок в браузере.

**Играть:** https://kabilzhanovkurbanali-coder.github.io/toguz-korgool/

- Игра против бота (лёгкий, средний, сложный) или вдвоём на одном устройстве
- Анимация посева со звуком, туз и захваты по стандартным правилам
- Ходы с клавиатуры (1–9), адаптив для телефона

Статическая сборка: логика игры и бот работают прямо в браузере, партии сохраняются в localStorage.
